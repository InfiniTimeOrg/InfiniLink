### Features:
- Discover and connect to nearby InfiniTime devices, with support for multiple watches
- Keep date and time in sync
- Battery, heart rate, and step charts, with battery health stats, resting heart rate, heart zones, and goal streaks
- Sleep tracking using the watch's heart rate and motion data
- Exercise tracking with live activities, custom exercises, route maps, splits, and GPX export
- Turn-by-turn directions sent to the watch using MapKit
- Inactivity, goal, heart rate, and water reminders
- Ring a lost watch and report the last known location
- Control Apple Music with InfiniTime's music controls
- Integration with Apple HealthKit, including sleep sync and individual sync toggles
- Weather fetch (using WeatherKit), and push (using InfiniTime 1.14's [Simple Weather Service](https://github.com/InfiniTimeOrg/InfiniTime/blob/main/doc/SimpleWeatherService.md))
- Watch settings, alarm, and watch face editing
- Watch file browser and uploading of [external resource packages](https://github.com/InfiniTimeOrg/InfiniTime/blob/develop/doc/gettingStarted/updating-software.md#updating-resources)
- Download and install InfiniTime firmware updates from GitHub releases, InfiniTime's automated builds, and local files

### Partially implemented features:
- System-wide notifications—implemented in [#2217](https://github.com/InfiniTimeOrg/InfiniTime/pull/2217), but not available in the main branch yet.

### Currently non-functional features:
- System-wide music controls—requires implementation of Apple Media Service.

### Planned features:
- Battery, heart, and step widgets
